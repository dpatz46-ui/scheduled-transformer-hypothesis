# Priority / status note

**Author and proposer:** Dustin Patzer, Independent Researcher.

This repository is intended as a dated public statement of the **Scheduled Transformer hypothesis** and of the empirical program designed to test it.

The theory is proposed here in advance of completion of the comprehensive confirmatory harvest. Preliminary primary-data analysis strongly indicates support, but the repository deliberately distinguishes those preliminary observations from completed confirmatory results.

Later empirical releases should preserve this version rather than rewriting its historical status.
